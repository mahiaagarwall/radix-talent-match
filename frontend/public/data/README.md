# Talent Check requirements drop-in location

Place the official facilitator file here as:

    frontend/public/data/talent_check_company_skillsets.json

The Talent Check page fetches `/data/talent_check_company_skillsets.json` on load.
If the file is absent, the page shows a setup state and offers a JSON import instead.

This file is **not** included in the hackathon starter ZIP. Do not create it by hand —
ask the facilitator for the official snapshot (see the participant brief, page 11).

The canonical repository copy should live at `data/talent_check_company_skillsets.json`.
